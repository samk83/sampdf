# 디자인 시안 기록

시안은 Owner가 `/design`으로 만들고, design-board 스킬이 지시문과 기록을 맡는다.
이번 프로젝트는 Owner가 "디자인해줘"라고 직접 요청해 **Claude가 시안을 직접 만든다** (design-board의 예외 조항). 같은 지시문으로 `/design`에서 다시 만들 수도 있다.
다음 세션은 이 파일을 읽고 이어서 진행한다.
