# 변경 이력

작업 단위마다 무엇을, 왜 바꿨는지와 확인 결과를 남긴다. 최신 항목이 위에 온다.

## 2026-10-12 — 0단계 엔진 검증

**무엇을**: C# 솔루션 뼈대, PDF 엔진 교체 경계(`IPdfEngine`/`IPdfDocument`), MuPDF.NET 구현, 안전 저장, 가상 도면 생성기, 검증 실행기, 자동 테스트 64개.

**왜**: 기획서 12장·17장에 따라 화면을 만들기 전에 "선택한 엔진으로 표준 PDF 주석을 저장하고 다시 열 수 있는가"를 먼저 판정하기 위해서.

**주요 결정**
- 엔진: MuPDF.NET (개인 로컬 사용이라 AGPL로 충분)
- 좌표: 엔진 밖에서는 "보이는 페이지 좌표"(회전·CropBox 반영, pt 단위)만 사용
- 파일은 메모리로 읽어 연다 (원본 잠금 없음 → 같은 경로에 안전하게 덮어쓰기 가능)
- 영역 하이라이트는 Multiply 혼합 반투명 사각형으로 저장
- Callout 지시선은 PDF 사전에 직접 기록 (MuPDF.NET의 CropBox 처리 오류 회피)

**확인**: Linux에서 `dotnet test` 64개 통과. 결과 PDF와 미리보기 이미지를 눈으로 확인. Windows, Acrobat, Bluebeam 확인은 아직 하지 않음.
