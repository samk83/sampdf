# 기획서: Sam Drawing Tools

> 원본: "도면 검토용 PDF 프로그램 개인용 기획서 v0.2"와 "DRAWING DIFFERENCE CHECKER — PRODUCT REQUIREMENTS v1.0"을 바탕으로, 이후 Owner 결정(웹 전환, PDF 중심, DWG·Word 제외, 오토캐드식 명령창·작도, 영어 기본·다국어 등)을 반영해 정리. 마지막 수정: 2026-10-16 (설계 승인 반영)

## 1. 목적
Bluebeam Revu에 익숙한 흐름으로 PDF 도면을 검토하고, 도면이 개정되었을 때 **바뀐 부분을 빠짐없이 자동으로 찾아 표시**한다. 결과는 다른 프로그램(Bluebeam·Acrobat)에서도 열고 고칠 수 있는 표준 PDF 주석으로 내보낸다.

## 2. 핵심 사용자와 사용 상황
- 사용자: Sam 한 명 (건축·구조 도면 검토자). 협업 기능 없음.
- 상황: 개정 도면을 받으면 이전 도면과 비교해 변경 사항을 확인하고, 구름과 △ 리비전 번호를 붙여 PDF로 정리한다. 가끔 도장·서명·도면 조각의 흰 배경을 지워 투명 PNG로 쓴다.
- 오래 켜 두고 큰 도면을 확대·이동하며 쓰는 **PC 작업용 도구**. 정보가 많아도 한눈에 읽혀야 한다.

## 3. 주요 기능 (우선순위 순)
| 순위 | 기능 | 설명 | 꼭 필요 / 나중에 |
|---|---|---|---|
| 1 | 도면 비교 | 원본·리비전(PDF, PNG·JPG·TIFF) 열기 → 자동 비교 → 글자 변경 하이라이트, 그림 변경 구름 + △ 번호(하나씩 올라감), 지워진 선 흐리게 | 꼭 (만들어짐) |
| 2 | 비교 검토 | 나란히/겹쳐 보기, 같이/따로 이동, 변경 목록(필터·이동·지우기), 표시 직접 수정(옮기기·크기), PDF 내려받기 | 꼭 (만들어짐) |
| 3 | 투명 PNG | 흰(한 가지 색) 배경 지우기, 기준 슬라이더, 가장자리 부드럽게, 여백 자르기 | 꼭 (만들어짐) |
| 4 | 도면 검토(마크업) | Bluebeam식 마크업 도구(구름·글상자·Callout·선·화살표·사각형·원·펜·하이라이트), 썸네일·책갈피, 마크업 목록(상태·필터), 속성, 저장 도구 | 꼭 (데스크톱에 있음 → 웹으로 옮길 예정) |
| 5 | 명령창 + 간단한 작도 (1단계) | 오토캐드식 명령창(모든 메뉴 호출·별칭·좌표 입력)을 비교·검토 모드 모두에. 선·폴리선·원·사각형·리비전 구름·글자·이동·복사·지우기, 내 레이어, 직교·격자, 내가 그린 것에 오스냅, 해칭(경계 그리기, 단색·빗금·격자·점·콘크리트) | 꼭 |
| 6 | 시작 화면 | 최근 파일, 새 비교, 파일 열기, 도구 바로가기 | 꼭 |
| 7 | 다국어 | 기본 영어, 한국어 등 추가. 화면 글자는 번역 파일로 분리, 명령 이름은 영어 고정 | 꼭 (영어 먼저) |
| 8 | 작도 2단계 | PDF 도면 선에 오스냅(끝점·중간점·교차점·중심·수직·근처점), 안쪽 클릭 해칭, PDF 원래 레이어 켜고 끄기, 축척 맞추기·거리 재기 | 나중에 |
| 9 | 비교 작업 저장·불러오기 | | 나중에 |
| 10 | 스캔 그림 글자 인식(OCR) | | 나중에 |

## 4. 화면 목록과 사용 흐름
| 화면 | 하는 일 | 대표 화면 여부 |
|---|---|---|
| 시작 | 최근 파일, 새 비교, 열기, 도구 고르기 | |
| 도면 검토 (마크업 작업 공간) | PDF 한 개를 보며 마크업 추가·수정, 썸네일·책갈피·마크업 목록·속성 | 2회차 |
| 도면 비교 — 파일 열기 | 좌우 칸에 원본·리비전 끌어다 놓기 (빈 상태) | |
| **도면 비교 — 결과 (나란히)** | 왼쪽 원본, 오른쪽 리비전 위 표시, 변경 목록, 내려받기 | **대표 (1회차)** |
| 도면 비교 — 겹쳐 보기 | 원본을 리비전 위에 투명도로 겹치기, 색으로 구분 | |
| 투명 PNG | 원래 그림·결과(바둑판) 나란히, 설정 | |
| 설정·내려받기 | 언어·단위, 오스냅 종류, 명령 별칭, 표시 설정(번호 방식, 글자도 구름, 제목란 무시), PDF 내보내기(편집 가능한 마크업 / 녹여 넣기) | |
| 포커스 모드 (F11) | 패널을 숨기고 도면만 크게, 떠 있는 도구·명령창 | |

흐름: 시작 → (도면 비교) 원본·리비전 열기 → 자동 비교 → 변경 확인·수정 → PDF 내려받기 / (도면 검토) PDF 열기 → 마크업 → 저장

주요 상태: 빈 화면, 파일 여는 중·비교 중, 오류(파일을 열 수 없음·암호 PDF), 차이 없음, 저장·내려받기 완료, 되돌리기(지운 변경·표시 수정)

## 5. 사용 환경
- 기기·OS·브라우저: Windows PC, Chrome/Edge, 화면 1440×900 기준(최소 1280)
- 온라인/오프라인: 내 PC 안에서만 동작 (127.0.0.1). 인터넷 없어도 기능 동작
- 데이터 저장 위치: 내 PC의 파일을 경로로 직접 열고 저장(처음 덮어쓸 때 `.bak`), 끌어다 놓은 파일은 메모리에 두고 저장할 때 위치를 물음. 설정·최근 파일·복구 사본은 앱 데이터 폴더(`%APPDATA%\SamDrawingTools\`). 자세한 것은 `docs/DESIGN-SPEC.md` 3장

## 6. 정한 기본값 (Owner가 바꿀 수 있음)
- △ 번호: 하나씩 올라감(1, 2, 3…), 글자 변경도 구름 표시
- 비교는 PDF 중심 (그림 파일은 글자 정보 없음 → 모두 구름)
- 아이콘 Lucide, 글꼴 Pretendard (명령창은 JetBrains Mono)
- 기본 언어 영어 (다국어 예정), 단축키는 오토캐드 방식
- 그린 것은 PDF 주석(편집 가능)으로 저장, 녹여 넣기는 내보낼 때 선택
- 도면은 CAD에서 뽑은 PDF가 기본 (스캔본은 오스냅이 내가 그린 것에만)

## 7. 위험과 대응
- Windows에서만 생기는 문제(한글 인코딩 등) → Owner 실행 확인으로 찾고 고친다
- 실제 도면의 비교 오탐 → 변경 목록에서 지우기·되돌리기, 설정(제목란 무시)으로 줄인다
- 마크업 작업 공간을 웹으로 옮기는 작업이 큼 → 시안 확정 후 단계로 나눠 진행
- "오토캐드처럼"은 범위가 끝없이 커질 수 있음 → 명령 목록을 1·2단계로 고정하고, 더 필요하면 회의 후 추가
- 큰 도면은 선이 수십만 개 → PDF 선 오스냅(2단계)은 빠른 검색 구조가 필요, 먼저 실제 도면으로 시험
