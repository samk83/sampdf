# DWG/DXF 비교 0단계 검증 결과

Drawing Difference Checker 기획서의 "DXF/DWG 비교 검증 → 판단 후 개발" 단계 결과다. 화면 없이 엔진만 시험했다.

- 모듈: `src/DrawingReview.Cad` (C#, **ACadSharp 3.8.0, MIT**)
- 테스트: `tests/DrawingReview.Cad.Tests/CadCompareTests.cs` — **13개 모두 통과** (Linux)
- 시험 도면: 테스트가 ACadSharp로 직접 만드는 가상 구조 평면 (그리드, 중첩 블록 기둥, 원, 호, 글자, 여러 줄 글자, 폴리선)
- **실제 AutoCAD·Revit에서 저장한 DWG로는 아직 시험하지 않았다.** 가장 중요한 남은 검증이다.

## 방식

1. **읽기**: DWG는 ACadSharp가 직접 읽는다 (R14~2018 형식, 현재 AutoCAD 저장 형식 포함). ODA 변환기는 쓰지 않는다. DXF도 같은 경로로 읽는다.
2. **정규화**: 블록 삽입을 풀어서(중첩 포함) 선·원·호·폴리선·글자 같은 기본 요소로 만든다. 좌표는 $INSUNITS를 보고 mm로 바꾼다.
3. **짝 맞추기**: 객체 ID(handle)를 쓰지 않는다. 같은 종류·도면층·좌표(허용 오차 0.5mm)·크기·글자이면 같은 객체로 본다. 대부분은 반올림 열쇠로 바로 맞추고, 경계에 걸린 것만 공간 색인으로 찾는다.
4. **분류**: 짝이 없는 것 중 모양이 같고 위치만 다르면 **이동**, 같은 자리에서 모양·글자만 다르면 **변경**, 나머지는 **추가/삭제**로 분류한다.
5. **경고**: 단위 없음, 단위 차이, 외부 참조(Xref) 미로드, 아직 비교하지 않는 객체 종류(개수 포함)를 경고로 알린다. 조용히 무시하지 않는다.

## 아직 검증하지 않았거나 지원하지 않는 것

| 항목 | 상태 | 위험도 |
|---|---|---|
| 실제 AutoCAD 2018~2025 저장 DWG | 미검증 | **높음**: ACadSharp는 커뮤니티 라이브러리라 일부 파일을 못 읽을 수 있음 |
| 치수(Dimension) 값·위치 비교 | 미구현 (경고로 개수만 표시) | 높음: 기획서 필수 항목 |
| 해치(Hatch), 스플라인, 타원, 3D 객체, 이미지 | 미구현 (경고) | 중간 |
| 배치(Layout)·뷰포트·Paper Space | 미구현 (Model Space만) | 중간 |
| 외부 참조(Xref) 내용 | 경고만 | 중간 |
| 동적 블록의 상태별 모양 | 미검증 | 중간 |
| 폴리선 볼록(bulge) 곡선 | 꼭짓점만 비교 | 낮음 |
| 화면 표시 (DWG 렌더링) | 없음 | 높음: 결과를 보여 주려면 직접 그리는 렌더러가 필요 |
| DXF로 Cloud 내보내기 | 미구현 | 중간 |

## 판단에 필요한 정보 (Owner 결정)

- **가능성**: 기본 요소 비교는 정확하고 빠르다. ACadSharp만으로 DWG를 직접 읽을 수 있어 ODA 변환기 없이도 출발할 수 있다.
- **가장 큰 위험**: ① 실제 DWG 파일 호환성, ② 치수 비교, ③ 결과를 보여 줄 DWG 화면 렌더러. 특히 ③은 지금까지의 PDF 기반 화면을 그대로 쓸 수 없어서 작업량이 크다.
- **추천**: 실제 DWG 샘플 2~3쌍(개인 도면이라도 됨)을 받아 ①을 먼저 확인한다. 통과하면 치수 비교 → 간단한 선 렌더러(비교 결과 확인용) → DXF Cloud 내보내기 순서로 개발한다. 실패하면 ODA File Converter로 DWG→DXF를 변환하는 보조 경로를 검토한다.
