## 색 역할
| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 기본색 | `--color-primary` | | 주요 버튼, 강조 |
| 강조색 | `--color-accent` | | 진행 상태, 포인트 |
| 배경 | `--color-background` / `--color-surface` | | 화면 / 카드 |
| 글자 | `--color-text` / `--color-text-muted` | | 본문 / 보조 |
| 상태 | `--color-success` · `--color-warning` · `--color-danger` | | 결과·경고·오류 |

## 글꼴
